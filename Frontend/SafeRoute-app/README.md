# Frontend SafeRoute

Interfaz web del sistema de recomendacion de rutas seguras. Utiliza React,
Vite, Leaflet y OpenStreetMap para mostrar delitos historicos, riesgo predicho
por segmento y la comparacion entre ruta corta y ruta segura.

## Ejecutar

```powershell
npm install
npm run dev
```

El backend debe estar disponible en `http://127.0.0.1:8000`.

## Verificar

```powershell
npm run lint
npm run build
```
